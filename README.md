# Database X-4
Website untuk memperkenalkan murid-murid dari kelas X-4 SMAN 23 Jakarta 2026-2027. Dibuat dalam rangka kegiatan Kokurikuler bertema 7 KAIH: Gemar Belajar.

Website ini dibuat oleh kelompok 2 bertema IT. Anggota kelompok meliputi:
1. Adila (2) (`adilanurfitriyani-dot`)
2. Hasbi (16)
3. Kiori (18)
4. Farahan (22) (`pieberer`)
5. Putri (30) (`putrinur8149-png`)
6. Samari (31)

## Jumlah Commit Sedikit?
Sebenarnya dalam pembuatan website ini banyak data langsung dimasukkan ke dalam repository. Dan ternyata, ini kesalahan besar. Jadi digunakan alat `git-filter-repo` untuk menghapus banyak sejarah commit sehingga tidak ada data sensitif yang publik, serta seluruh data dipindahkan ke backend terpisah menggunakan Supabase.
